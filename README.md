# Tillpoint (demo)

**This is a demo repository for [Fired](https://github.com/pa/fired)**, a Slack agent that runs
GitHub issues with a small classifier instead of a chat LLM. Tillpoint is not a real product.
The issues here are realistic examples so the agent has something to work on.

Tillpoint is a small payments API and merchant dashboard: charges, refunds, payouts, webhooks
and hosted checkout.
